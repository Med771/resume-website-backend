# Города студента

Город анкеты выбирается из справочника `cities`. У города есть id и уникальное имя. Одинаковые имена без учёта регистра — один город.

Читать справочник можно без входа: регистрация студента идёт без cookie. `GET /city/{id}` и `POST /city/filter` открыты всем. В фильтре необязательная подстрока имени. Создать, переименовать и удалить город может только админ.

В анкете остаётся строка `city`: это имя из справочника. В конце ответа и запросов добавлен необязательный `cityId`. Если передан `cityId`, берётся этот город. Если его нет, а клиент прислал текст `city`, сервер ищет имя без учёта регистра. Неизвестное имя город не создаёт и отвечает **400**. Пустое поле на правке город не стирает.

Удаление города не удаляет студентов: ссылка становится пустой. Полнота анкеты по-прежнему требует город, уже из справочника.

Снимок анкеты хранит название строкой. При чтении старого снимка имя остаётся в `city`, а `cityId` пустой, если этого имени в справочнике нет.

Города работодателя и вакансии этой таблицей не пользуются.
