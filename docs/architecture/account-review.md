# Цикл проверки анкеты

Статус аккаунта говорит, на каком шаге проверка. Показ карточки в каталоге — отдельный флаг `catalogVisible`. Каталог студента и работодателя берёт только `APPROVED` с подтверждённой почтой и полной анкетой. Пока правка снова на проверке, карточки в списке нет.

## Статусы

| Статус | Когда |
|---|---|
| `REGISTRATION` | Студент только зарегистрировался. Одобрить нельзя. |
| `IN_REVISION` | Студент заполняет или правит анкету. Одобрить нельзя. |
| `PENDING_APPROVAL` | Студент нажал «на проверку». Админу: проверь меня. |
| `APPROVED` | Админ одобрил. Анкета соответствует требованиям. |
| `REJECTED` | Админ отправил на доработку. Студент ещё ничего не менял. |

Правка своей анкеты — карточка (`PATCH /student/me`), фото, опыт, учёба, портфолио. Из `REGISTRATION`, `APPROVED` или `REJECTED` статус становится `IN_REVISION`, карточка скрывается, причина отказа очищается. Уже `IN_REVISION` или `PENDING_APPROVAL` правка не меняет. На проверку переводит только `POST /student/me/submit-for-review`. Правка админом статус не меняет.

Список студентов `GET /admin/account-approvals/students` отдаёт `hasPortfolio`, `hasExperience` и `hasEducation`: есть ли хотя бы одна запись портфолио, опыта и учёбы.

`POST /admin/account-approvals/{userId}/approve` ставит `APPROVED` и включает показ. Из `REGISTRATION` и `IN_REVISION` одобрение отвечает **400**. `reject` отправляет студента на доработку и из ожидания, и из `APPROVED`: статус становится `REJECTED`, карточка скрывается, уходит письмо с причиной. Пока студент сам ничего не менял, статус остаётся `REJECTED`.

## Показ карточки

`catalogVisible`:

- `true` только вместе с `APPROVED`. Одобрение включает показ.
- `REGISTRATION`, `IN_REVISION`, `PENDING_APPROVAL` и `REJECTED` всегда `false`. Включить показ у такого студента нельзя.
- Уже одобренного студента админ может скрыть, не забирая одобрение: статус остаётся `APPROVED`, `catalogVisible` становится `false`. Следующее одобрение снова включает показ.

Каталог студента и работодателя дополнительно требует `APPROVED`, подтверждённую почту и полную анкету. Студент на проверке не виден в списке, даже если флаг когда-то был включён.

`publicProfileConsent` устарел и остаётся в карточке. Каталог для вошедших на него не опирается.
