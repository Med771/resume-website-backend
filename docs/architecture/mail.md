# Письма

Сервер сам отправляет письма ниже. Тему и основной текст задаёт код. Администратор пишет только отказный комментарий и рассылку.

В письмах нет Telegram: при регистрации студента это поле указать нельзя.

## Готовые тексты

### Код подтверждения почты студента

После `POST /auth/register-student` и при повторной отправке кода.

Тема: «Код подтверждения — Singularity Resume».

```
Здравствуйте!

Рады, что вы с нами. Вот код, чтобы подтвердить почту: 1234

Он действует 15 мин. Никому его не сообщайте.

Если вы не запрашивали код, просто проигнорируйте это письмо.
```

### Общий код подтверждения

Та же тема. Тело короче.

```
Здравствуйте!

Ваш код подтверждения: 1234

Код действует 15 мин. Никому не сообщайте этот код.

Если вы не запрашивали код, просто проигнорируйте это письмо.
```

### Код смены пароля

После `POST /auth/forgot-password`.

Тема: «Код для смены пароля — Singularity Resume».

```
Здравствуйте!

Вот код для смены пароля: 1234

Ваш логин: ivan

Код действует 15 мин. Никому его не сообщайте.

Если вы не запрашивали смену пароля, просто проигнорируйте это письмо.
```

### Регистрация завершена

Когда студент подтвердил почту. Анкета ещё не отправлена.

Тема: «Регистрация завершена — Singularity Resume».

```
Здравствуйте!

Почта подтверждена.

Ваш логин: ivan

Дальше заполните анкету и отправьте её на проверку.
```

### Анкета отправлена

Когда студент отправил анкету на проверку.

Тема: «Анкета отправлена — Singularity Resume».

```
Здравствуйте!

Анкета отправлена на проверку.

Когда администратор её одобрит, пришлём письмо.
```

### Аккаунт одобрен

После одобрения студента.

Тема: «Аккаунт одобрен — Singularity Resume».

```
Здравствуйте!

Администратор одобрил анкету. Карточка видна в каталоге.

Ваш логин: ivan
```

### Аккаунт не одобрен

После отказа студенту.

Тема: «Аккаунт не одобрен — Singularity Resume».

```
Здравствуйте!

Администратор не одобрил ваш аккаунт.

Причина: Анкета заполнена недостаточно

Ваш логин: ivan
```

Готовые формулировки причины:

| Код | Текст |
|---|---|
| `INCOMPLETE_PROFILE` | Анкета заполнена недостаточно |
| `INVALID_DATA` | Данные или контакты выглядят некорректно |
| `NOT_ELIGIBLE` | Аккаунт не подходит под правила площадки |
| `DUPLICATE` | Такой аккаунт уже есть |

## Тексты администратора

Комментарий к отказу и причина `OTHER` попадают в то же письмо. Для `OTHER` строка причины — комментарий администратора. Если комментарий совпадает с готовой формулировкой, второй раз он не печатается.

```
Здравствуйте!

Администратор не одобрил ваш аккаунт.

Причина: Анкета заполнена недостаточно

На фото не видно лица.

Ваш логин: ivan
```

Рассылка `POST /admin/students/mail`. Тему и текст задаёт администратор. Сервер подставляет данные каждого получателя.

Плейсхолдеры: `{{studentId}}`, `{{firstName}}`, `{{lastName}}`, `{{name}}`, `{{username}}`, `{{email}}`, `{{course}}`, `{{busyness}}`, `{{speciality}}`. Пустое поле даёт пустую строку. Незнакомый `{{...}}` остаётся как есть.

```
Тема: Здравствуйте, {{firstName}}

{{name}}, ваша анкета на курсе {{course}} принята.
```
