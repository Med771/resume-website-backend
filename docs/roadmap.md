# Ограничения

Это то, чего в текущем коде нет. Поля и статусы, которые уже работают, описаны в [backend.md](./backend.md) и [api-endpoints.md](./api-endpoints.md).

- Вход в WebSocket (`/ws`) не проверяет JWT. Кто знает адрес, может открыть handshake.
- Уведомления во входящие живут только в WebSocket. После перезагрузки страницы история уведомлений с сервера не приходит.
- Повторный `POST` заявки, сообщения или события аналитики сервер не делает идемпотентным.
- В `users` остались колонки `first_name`, `last_name`, `email`, в `skills` — `speciality_id`. Код их не читает и не пишет.
